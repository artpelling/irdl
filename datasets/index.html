Datasets#

irdl currently supports the following dataset groups.

Your preferred Dataset is not listed?

Have a look at the guide to Adding a new Dataset.

Room Impulse Responses#

BrasRs8Dataset()

Download the BRAS RS8 dataset from DepositOnce.

MiracleDataset()

Download the MIRACLE database from DepositOnce.

MultiRoomTransitionDataset()

Download the MRTD dataset from Zenodo.

MyriadDataset()

Download the MYRiAD database (RIR subset) from Zenodo.

SrirachaDataset()

Download and merge the SRIRACHA database from DepositOnce.

Head Related Impulse Responses#

FabianDataset()

Download and extract the FABIAN HRTF database from DepositOnce.

HutubsDataset()

Download the HUTUBS HRTF database from DepositOnce.
